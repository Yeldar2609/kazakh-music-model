Candidate lyric/poem texts for the 45 sung RTRK recordings (data/raw/rtrk_kazakh_traditional_audio), one file per recording, found by title on wikisource.org, kk.wikipedia.org and public-domain/folk-text sites; INDEX.csv lists source URL, licence and notes for each.
NONE of these texts has been checked against the audio: every file is marked UNVERIFIED and must be compared with the recording by a Kazakh speaker before any use (the RTRK archive ships no transcripts, several titles are generic, and 'candidate poem' files only identify the poet, not the poem).
Hit rate: zhyr_terme 8/20 full text + 1 reference-only; an_kompozitor 14/15 full text; besik 10/10 full text (the same common lullaby text is repeated in all ten besik files because the sung variant is unknown).
Full text was copied only where the text is public domain (author died before 1950, or a traditional anonymous folk text) or CC BY-SA (Wikimedia); for pages with a named author of unknown dates and no site licence only the first two lines are kept ('reference only'). Texts are copied as the source has them (Cyrillic, spelling untouched; only HTML/wikitext markup and repeated spaces were removed).
Files with source NOT FOUND carry a one-line note of what was tried; do not fill them from memory.
